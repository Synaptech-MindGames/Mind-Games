What does the filename mean?

S1R1I1_1

S1 = participant 1 · R1 = run 1 · I = imagery recording set · 1 = task code 1 · _1 = first trial/repetition for that task.

Important: Although the filename contains I for the imagery set, task code 1 is BEO (baseline eyes open), not a hand or foot motor-imagery task.

How to interpret this recording

  • EEG records voltage differences measured at scalp electrodes; it is not a direct readout of thoughts or focus.
  • These channels are located at: FC5, F3, Fz, F4, FC6, FC1, FC2, Cz, T7, CP5, C3, CP1, CP2, C4, CP6, T8 (10–10 electrode naming system).
  • Frequency bands are patterns in the signal, not meanings attached to individual waves. Alpha, beta, theta and other rhythms require frequency analysis.
  • This dataset was hardware-filtered at 5–50 Hz with a 60 Hz notch filter, so it is not completely unfiltered raw amplifier output.
  • Large spikes or noisy sections may be artifacts (for example, movement, muscle tension, or electrode contact). A waveform alone cannot identify their cause with certainty.

Dataset: MILimbEEG, recorded with OpenBCI Cyton + Daisy, 16 channels, 125 Hz. Channel order and task labels follow the dataset documentation.
